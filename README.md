# スキルアップカレッジ 公開原稿

[スキルアップカレッジ](https://skillup.college/) で公開している学習コースの原稿を、GitHub 上でも読める「1コース＝1Markdownファイル」の形式に整理して公開しています。

## スキルアップカレッジについて

スキルアップカレッジは、株式会社エレファンキューブが運営する**テキスト中心の無料学習プラットフォーム**です。断片的な情報ではなく体系的に学べることを重視し、「本を読むように自分のペースでじっくり知識を積み上げたい」層に向けて、各分野の入門コースを公開しています。

- **公式サイト**：https://skillup.college/
- **コース一覧**：https://skillup.college/courses/

## このリポジトリの目的

- スキルアップカレッジのコース原稿を、テキストとして読める形でも公開・参照可能にする
- GitHub 上で全文検索・ブックマーク・コピーなどがしやすい形式を提供する
- フィードバック（誤字・事実誤認の指摘など）を Issue 経由でも受け付けられるようにする

サイト本体では、確認クイズの即時採点・用語集モーダルでの即時参照・学習進捗管理など、Web ならではの学習体験を提供しています。**実際に学習される方は、ぜひ [skillup.college](https://skillup.college/) でご受講ください。**

レッスン単位までの目次（全コース横断）は **[INDEX.md](./INDEX.md)** にまとめています。コース全体をざっと俯瞰したい場合や、AIアシスタントに本リポジトリを参照させる場合の入口としてご利用ください。機械処理向けの同等データは [index.json](./index.json) に置いています。

## 各ファイルの構成

各コースのMarkdownファイルは、以下のセクションで構成されています。

1. コース題名・サブタイトル
2. メタ情報（カテゴリ／難易度／所要時間／公開日／最終更新日／コースURL）
3. 対象者・前提知識・学習目標
4. コース概要・学習の流れ
5. レッスン一覧
6. 各レッスンの本文＋確認クイズ
7. 総復習テスト
8. 用語集
9. 参考資料
10. 利用規約・二次創作ルール・著作権

確認クイズは GitHub Markdown のチェックボックス記法で表示されます。`[x]` が正解、`[ ]` が不正解で、各問題に解説が付いています。
